Reusable UI components shared across pages.

|---|---|
| `outputMarkdown.tsx` | Renders assistant output as Markdown (used in chat panels). |
| `AppleTaskComposer.tsx` | Input composer for task-style prompts. |
| `LanguageSwitch.tsx` | i18n language toggle. |
| `bomData.ts` | BOM (Bill of Materials) data helpers. |
| `execution-flow/` | Visual execution-flow diagram component. |
