# frontend/src/pages

Application page components.

| File | Purpose |
|---|---|
| `AgentPage.tsx` | Main application shell. It hosts the workspace navigation and mounts the Mission Studio panels from `pages/agent/`. |
| `HomePage.tsx` | Landing page. |
| `GncWorkspacePage.tsx` | GNC configuration and telemetry dashboard. |
| `ComplianceCheckPanel.tsx` | Compliance-check results display. |
| `EarthPage.tsx` / `V3Page.tsx` / `ModelViewerPage.tsx` | 3D viewer variants. |
| `WorkspacePageShell.tsx` | Layout shell for legacy workspace pages. |
| `SplineBotPage.tsx` | Spline bot demo. |
| `RegionWorkspacePage.tsx` | Region workspace view. |
| `pages/agent/` | Mission Studio components: GMAT mission authoring, results, and discussion. |
| `pages/workspace/` | Legacy workspace management. |
| `pages/viewer3d/` | 3D viewer utilities. |
