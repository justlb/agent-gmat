# frontend/tests

Vitest test suite. Run with `npm test` from `frontend/`.

| Directory | Covers |
|---|---|
| `pages/agent/` | MissionV2, ResultsPage, MissionOverview component tests. |
| `pages/workspace/` | Legacy workspace page tests. |
| `pages/viewer3d/` | 3D viewer tests. |
| `components/` | Reusable component tests. |
| `hooks/` | Custom hook tests. |
| `app/` | App-level tests. |
| `test/` | Shared test setup/fixtures. |
| `utils/` | Test utilities. |
