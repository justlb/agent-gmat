# docs

Technical documentation for the GMAT Agent project.

| Directory / File | Purpose |
|---|---|
| `CODE_STRUCTURE.md` | Module boundaries, data-retention rules, commenting convention. |
| `HANDOVER.md` | Operational handover guide for the next maintainer. |
| `RESULTS_AUDIT.md` | Finalisation audit of the Results page (run-scoped discussion, charts, comparisons). |
| `RESULTS_CALCULATION_CONTRACT.md` | Definitions, units, approximations, and evidence for the computed Results indicators. |
| `OPALIS_INPUT_CONTRACT.md` | Contract defining OPALIS authorised input sources (CIC files + satellite.json). |
| `architecture/` | Architecture Decision Records (ADRs). |
| `mvp/` | MVP decision records (connectivity, values, rendering). |
| `tutorials/` | User-facing guides (use the project, launch, install, add satellite, add scenario). |
